Where Is Insights & Reports?

Admin login: Sidebar → Developer Tools → Insights & Reports.

Supervisor: the backend allows management reports, but the current frontend sidebar does not show Insights & Reports for Supervisor. Use the Admin account to demonstrate it from the UI.

Quick Demo Order

Use Admin login, then open Dashboard, People Directory, Pet Directory, Health Records, Payroll, and finally Developer Tools → Insights & Reports for the report-only views.
