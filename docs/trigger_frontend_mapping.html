PetCare: Database Triggers in the Frontend

Mapping for triggers defined in database/01_schema.sql.

Trigger Frontend Location Role / Login What It Demonstrates
TRG_PERSON_AUTO_ID User Accounts, People Directory, Create Account Admin, Supervisor, public registration When a person is inserted with null PERSON_ID, Oracle generates P###.
TRG_SYSTEM_USER_AUTO_ID User Accounts, People Directory, Create Account Admin, Supervisor, public registration When a login account is inserted with null USER_ID, Oracle generates U###.
TRG_PET_AUTO_LOCAL_ID Pet Directory, Rescue Intake Admin, Employee, Supervisor New local pets get LP###; guest pets get GP### through PETCARE_ID_CONTEXT.
TRG_MEDICAL_RECORD_AUTO_ID Health Records Employee, Doctor New medical records get MR### automatically.
TRG_RESCUE_AUTO_ID Rescue Operations Volunteer New rescue reports can receive generated rescue IDs such as R###.
TRG_ADOPTION_AUTO_ID My Adoption Applications Adopter New adoption applications receive generated IDs such as AD###.
TRG_AUDIT_LOG_ID System Activity Admin Every audit row receives a generated numeric audit ID, displayed in the UI as AU###.
TRG_ADOPTION_STATUS_AUDIT Adoption Review, My Assigned Adoptions, System Activity Supervisor, Employee, Admin When adoption status changes, Oracle inserts an audit row. Admin sees it in System Activity.
TRG_ROLE_APP_NO_OWNER Role Applications All logged-in users Prevents requesting the Owner role through role applications.
TRG_SALARY_PAYEE_ROLE Payroll Supervisor Validates that the selected payee actually has the chosen Supervisor, Employee, or Doctor role.

Best Trigger Demo Order

1. Admin → User Accounts → create a Supervisor. Show generated P### and U###.

2. Employee/Admin → Pet Directory → create a pet. Show generated LP### or GP###.

3. Employee/Doctor → Health Records → create a health record. Show generated MR###.

4. Supervisor → Adoption Review → approve/reject an application, then Admin → System Activity. Show audit entry AU###.

Important Note

Browser messages such as “Please fill out this field” are frontend HTML validation, not database triggers. Database triggers run only after an insert or update reaches Oracle.
