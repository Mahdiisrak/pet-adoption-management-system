PetCare: PL/SQL in the Frontend

Mapping for database/06_plsql.sql functions/procedures and their visible UI workflows.

PL/SQL Object Frontend Location Role / Login What to Click / Show
FN_PERSON_AGE Smart PetCare Tools → Age Calculator Admin, Doctor Enter a person ID such as P001 and click Calculate Age. Invalid IDs show NO_DATA_FOUND.
FN_AVAILABLE_PET_COUNT Smart PetCare Tools → Age Calculator result Admin, Doctor The same Calculate Age button also returns Available Pets.
PR_CURSOR_PET_SUMMARY Smart PetCare Tools → Pet Availability Summary Admin, Doctor Click Generate Summary to show total registered pets and available local pets.
PR_FIND_PERSON Smart PetCare Tools → Person Lookup Admin, Doctor Enter P999 and click Search Person to demonstrate handled NO_DATA_FOUND.
PR_SUBMIT_ADOPTION My Adoption Applications Adopter Select an available pet and submit an application. The procedure creates a pending adoption request.
PR_REVIEW_ADOPTION Adoption Review Supervisor Approve and assign an employee, or reject a pending adoption application.
PR_MARK_ADOPTED My Assigned Adoptions Employee Finalize an approved assigned adoption. The pet becomes adopted.
PR_OWNER_DIRECTORY Pet Owners Admin, Supervisor, Employee Search by exact owner ID, name, or phone. No match returns the handled message No records available.
PR_CREATE_PERSON No direct frontend button in the current UI Database/demo script only Used as a PL/SQL insert example with duplicate-key exception handling. The app creates people through API transactions instead.

Where Is Smart PetCare Tools?

Admin login: Sidebar → Developer Tools → Smart PetCare Tools.

Doctor login: Sidebar → Clinical Tools → Smart PetCare Tools.

Supervisor: the current frontend sidebar does not show Smart PetCare Tools for Supervisor. Use Admin or Doctor for the PL/SQL demo page.

Best Viva Demo Order

Start with Admin login → Smart PetCare Tools. Show Age Calculator, then Pet Availability Summary, then Person Lookup with P999. After that, show the adoption workflow procedures through Adopter, Supervisor, and Employee pages.
